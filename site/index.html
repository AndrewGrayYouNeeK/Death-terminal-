AI

Ghost text

After you pause about 300 ms at a prompt, dim text shows how the command might finish. The shell never sees it. Suggestions stay off the alternate screen (vim, less, htop) and only appear when the cursor is at the end of the line.

Tab accept · Esc dismiss · Alt+] / Alt+[ next and previous. config.ai.accept_key changes the accept chord.

Local model, or Grok

No config file is required. The default endpoint is Ollama at http://localhost:11434/v1 with qwen2.5-coder:0.5b, so nothing leaves the machine. If Ollama is not running, the terminal stays usable and shows a small “AI offline” badge plus one hint: ollama pull qwen2.5-coder:0.5b. If Ollama is up but that model is missing, the hint says so. deathterminal --ai-setup prints the same check. Any OpenAI-compatible chat server works. api.x.ai and us.api.x.ai use the Responses API with model grok-4.7. Put the key in an env var named by config.ai.api_key_env (XAI_API_KEY for Grok). The key is not stored in the config file.

On xAI, config.ai.reasoning is low, medium, high, or xhigh. Empty means low. Reasoning cannot be turned off. Live search is off, and the response is not stored. The wait is at least 15 seconds.

Explain the last error

An overlay names the cause of the last failed command and suggests a fix. Esc closes it. If the endpoint is down, the overlay says so.

Ctrl+Shift+A

Ask the Output

A prompt bar sends your question with the selection, otherwise the last command’s output, otherwise the visible screen. The answer cites lines, which are highlighted. Long output is cut to config.ai.ask.max_lines (default 200) and the overlay says so. Turn it off with config.ai.ask.enabled = false.

Ctrl+Shift+Q · macOS Cmd+Shift+Q · Down and Enter jump between cited lines · Esc closes

Speaks in your voice

Explain, Ask the Output, the Ghost Run note, and the Time Travel summary are read aloud. Ghost-text completions are not. The default voice is the ElevenLabs clone QMnwdN2oOwNXPcl9oXIl (“GQ”), model eleven_flash_v2_5. The key is only the environment variable ELEVENLABS_API_KEY. It is never a config field. If the key is missing or the service is down, speech is skipped and one short hint is shown. A new answer or Esc stops the clip. macOS plays it with afplay. Linux tries paplay, then ffplay, then mpg123. Windows uses PowerShell MediaPlayer, or skips if that fails.

Ctrl+Shift+Alt+V mute or unmute · macOS Cmd+Shift+Option+V · command palette “AI: mute or unmute voice” · --no-voice · config.ai.voice.enabled = false

Redaction and the offline badge

Tokens, keys, passwords, and env assignments are stripped before a request is sent. If the endpoint is down, a small “AI offline” badge shows and requests back off. --no-ai turns suggestions off.

Shell integration

OSC 133 marks are injected for bash, zsh, and fish so suggestions, Muscle Memory, and Time Travel know the typed command, the directory, and the exit code. config.shell.integration defaults to on. It applies on the next start.

deathterminal --print-shell-integration bash (or zsh, fish)

Ghost Run

Hold a risky Enter

Enter on a built-in risky pattern does not reach the shell. A local read-only preview estimates the impact. The command is not executed to build that preview. An optional plain-English note is added when config.ghost_run.ai_explain and config.ai.enabled are both on.

y run · n, Esc, or Ctrl+C cancel · t snapshot with Time Travel, then run · a second Enter does not confirm

What it matches Preview can be partial

The built-in list covers rm -r / -R / --recursive, git reset --hard, git clean (not a dry run), force push, dd, mkfs*, chmod -R, chown -R, find -delete / -exec / -execdir, mv onto an existing path, a truncating >, and curl or wget piped to a shell. Wrappers such as sudo and env are skipped. There is no regex. Assigning config.ghost_run.patterns, even to {}, replaces that list.

Directory walks stop after 4000 entries or about 200 ms and say the preview is partial. Git estimates time out after about 1.5 s. mv onto an existing path is not checked on an SSH pane. t is hidden in headless mode, because Time Travel does not register a snapshot there. If the snapshot fails, the command is not run.

Muscle Memory

Repeated sequences This machine only

The same 2–5 commands, in one project, at least three times, raises “You run these together a lot. Make it a shortcut?” Nothing is sent to a model. Commands that look like secrets are not stored.

y or Enter name it · n or Esc dismiss that sequence · prefix the name with * to save it for every directory · Ctrl+Shift+P can save, run, rename, or delete it

Run a shortcut

Type the name at the prompt and press Enter, or pick it in the command palette. With shell integration, each command is sent on its own and the rest stop after a non-zero exit. Without it, the sequence is one line joined with &&. A project shortcut wins over a global one with the same name. The file is shortcuts.lua in the config directory.

config.muscle_memory.min_repeats (default 3) · config.muscle_memory.max_len (default 5)

Time Travel

Rewind a directory GUI only

Before each command (OSC 133 C), the working directory from OSC 7 is snapshotted. After the command, the overlay can show added, removed, and modified paths. Headless mode does not take snapshots. An SSH pane is skipped, because the remote directory is not the local tree. Symlinks are stored as the link text and are not followed.

Ctrl+Alt+T open or close · macOS Cmd+Option+T · Up / Down scrub · Enter then y rewind · n or Esc cancel · u undo the last rewind

What is kept

Ctrl+Shift+T and Cmd+T stay New Tab. Snapshots live under the data directory and try an APFS clone or a Linux reflink before a byte copy. A root .gitignore applies. The default excludes include node_modules, .git/objects, zig-out, target, virtualenvs, and dist. Trees bigger than config.time_travel.max_dir_mb (200) are skipped, and a rewind of a folder that has grown past that cap is refused. Each pane keeps config.time_travel.retention snapshots (50). A one-line AI summary is optional and uses the same redaction as other AI calls.

Shared Haunting

Share the focused pane

One other YouNeeK Death Terminal can watch the pane that was focused when the share started. Later focus changes do not follow. The guest gets the live cells, not the scrollback, and not other panes or the invite banner. The session is Noise (X25519 + ChaCha20-Poly1305). The relay only forwards opaque frames.

Ctrl+Shift+H · macOS Cmd+Shift+H · or deathterminal --share

Short code, LAN, then the relay

A guest on the same Wi-Fi connects to the host directly. Anyone else uses the relay already in the invite. The default relay is wss://relay.youneek.xyz. If that custom domain returns an empty 404 or a 403 before the Worker runs, both sides dial wss://youneek-share-relay.youneekartifacts.workers.dev with the same session. config.share.relay = "off" keeps the share on the LAN. A wss:// URL, or deathterminal --share-relay <host:port>, is a relay you run yourself. The TCP flag is a splice, not the default WebSocket path.

When the hosted relay accepts the session, the banner leads with a short code such as K7Q-4MZ (drawn with spaces). Copy puts deathterminal --join K7Q-4MZ on the clipboard. The short code is kept for about an hour and only a few lookups. A long dt1 invite still works. Ctrl+Shift+J (macOS Cmd+Shift+J) opens a join prompt. deathterminal --join also takes a deathterminal://join/ link.

Read-only, then control Screen is not redacted

The guest starts read-only. Arrows move their cursor. The host grants or revokes typing for this session. A new guest after a kick is read-only again. Passwords visible in the pane are sent as they appear. Do not share a pane you would not show.

Ctrl+Shift+G grant or revoke · macOS Cmd+Shift+G · F12 kick, or stop if you are still waiting · Ctrl+Shift+Alt+H always stop · macOS Cmd+Shift+Option+H

What the wire leaves out Partial

Combining characters and underline styles are not sent. Colours are resolved RGB. A smaller guest window clips. config.share.enabled = false refuses to host. --join still works. The command palette has “Share: copy invite”.

SSH

Built-in client Linux only

libssh2 1.11.1 is compiled in on Linux. On macOS and Windows, --ssh reports that it is unavailable. A target is a config.ssh.profiles name, a ~/.ssh/config Host, or user@host[:port]. Host, HostName, User, Port, IdentityFile, ProxyJump, and Include are read. Match blocks are skipped.

deathterminal --ssh prod · Ctrl+Shift+S palette · Enter opens a tab · Shift+Enter splits right · Alt+Enter opens a window

Keys, prompts, and forwards

Host keys use ~/.ssh/known_hosts. An unknown host can be saved, accepted once, or rejected. A changed or @revoked key is refused, with no override. Auth tries ssh-agent, key files (including encrypted PEM, PKCS#8, and OpenSSH keys), keyboard-interactive, then password. Prompts stay in the terminal. Forwards are -L, -R, and -D (SOCKS). The palette toggles them on the focused session. Keepalives default to 30 s. reconnect = true on a profile dials again after a drop.

deathterminal --ssh-ctl <pid> status|list|toggle <n>|add <spec>|reconnect

SSH limits Partial

No certificates, no Match, no X11 or agent forwarding, and no SFTP. ProxyJump hops do not follow their own jump. A profile command is typed into the remote shell, not sent as an exec request. mv overwrite checks from Ghost Run do not run on an SSH pane.

Tabs, panes, and text

Tabs and splits

Each pane has its own shell or SSH session, grid, scrollback, selection, search, and AI context. The tab bar is automatic once there are two tabs (config.tabs.bar can force top, bottom, or hidden). Markers show a bell, a failed command, a running command, and new output. New tabs inherit the focused pane’s directory when the shell sent OSC 7.

Ctrl+Shift+T new tab · Ctrl+Shift+Alt+W close tab · Ctrl+Tab / Ctrl+Shift+Tab cycle · Alt+1…9 go to a tab · Ctrl+Shift+E split right · Ctrl+Shift+O split down · Ctrl+Shift+W close pane · Alt+arrows focus · Alt+Shift+arrows resize · Ctrl+Shift+Z zoom pane · Ctrl+Shift+Alt+E equalize

Mouse on the tab bar

Click a tab to switch, drag to reorder, double-click to rename, click × or middle-click to close, and click + for a new tab. Drag a divider to resize. Closing a pane that is running a program (not just the shell) asks first.

Ctrl+Shift+Alt+R rename the tab

Selection, search, scrollback

Drag to select. Double-click a word, triple-click a line, Shift+click to extend, Ctrl+Alt+drag for a block. Shift selects even when the app owns the mouse. Scrollback defaults to 10,000 lines, with a thumb while you are scrolled back. Search highlights matches.

Ctrl+Shift+C copy · macOS Cmd+C · Ctrl+Shift+V paste · macOS Cmd+V · Ctrl+Shift+Alt+A select all · macOS Cmd+A · Ctrl+Shift+F search · Shift+PgUp / PgDn page · Shift+Home / End top and bottom

Clipboard and links

Release copies to PRIMARY on Linux. selection.copy_on_select also copies to the clipboard. Multi-line paste asks when bracketed paste is off. OSC 52 defaults to write. Ctrl+click opens an OSC 8 link or a URL with xdg-open, open, or ShellExecute. No shell is involved.

Rendering and fonts

Vulkan, then software

A swapchain and a glyph atlas draw the grid. If Vulkan is missing, the software path still paints: XPutImage or wl_shm, a Win32 DIB, or a CGImage. There is no animation and the cursor does not blink, so an idle window does not wake the CPU. Present mode defaults to vsync (fifo). Redraws while output streams are capped at config.render.max_fps (120).

--backend auto|x11|wayland|win32|cocoa · --scale 1–4

JetBrains Mono, zoom, retro

JetBrains Mono is embedded, so a window works with no system font. Ligatures are on and stay one cell wide. Ctrl+=, Ctrl+−, and Ctrl+0 zoom. --font retro or config.font.retro = true switches to the built-in 8×8 bitmap, which is ASCII plus box drawing and has no bold or italic. Linux uses fontconfig for fallback glyphs. Windows and macOS scan their font folders and build FreeType and HarfBuzz from source. Colour emoji uses COLR fonts. Bitmap emoji such as Apple Color Emoji is not loaded. Emoji ZWJ sequences are drawn as separate code points.

Ctrl+= / Ctrl+− / Ctrl+0 · --font-family · --font-size · --line-height

Themes and the YouNeeK Time clock

death, and the other themes

config.theme defaults to death: light gray text, a black background, and a red cursor (#FF0033). Also bundled: default (classic ANSI), dracula, gruvbox-dark, nord, solarized-dark, and solarized-light. config.colors.* overrides one entry. Saving config.lua recolours text already on screen. Cursor shape is block, underline, or bar. Programs can still change it with DECSCUSR.

config.theme = "nord" · Ctrl+Shift+R reload now

YouNeeK Time On by default

The status bar shows a clock. The hour is the civil hour, in 12-hour or 24-hour form (settings.hours, default 24). Each hour has 100 YouNeeK minutes: one minute is 36 real seconds, so 14:30:00 civil is 14:50 and 14:59:59 is 14:99. mode = "regular" shows the civil minute instead. The moon phase is drawn next to the time. The accent is #7CFF6B. settings.chime toasts when the civil hour changes. It is off by default, and plugins cannot play a sound. Time zone is local, UTC, or an offset such as -05:00.

Ctrl+Shift+B show or hide the status bar · config.plugins["youneek-time"].settings

Startup banner

An interactive launch prints a green ASCII skull and “YouNeeK Death Terminal” on the terminal’s stderr. It is skipped when stderr is not a TTY. There is no separate window splash, and the mark is the green skull, not a terminal-window icon.

Config and plugins

config.lua

Lua 5.4 is compiled in. The file is --config, then $XDG_CONFIG_HOME/death-terminal/config.lua, then the system config dirs. Windows uses %APPDATA%\death-terminal\config.lua. A legacy config.txt still loads, with a deprecation note. Flags beat the file. Saving the file reloads it. A bad file at startup is ignored. A bad reload keeps the previous settings. Esc dismisses the error bar.

deathterminal --print-default-config · Ctrl+Shift+R · Ctrl+Shift+P command palette (macOS Cmd+Shift+P)

Plugins

Each plugin is its own sandboxed Lua state, with a memory cap, a CPU budget, and only the permissions you grant. YouNeeK Time is embedded and loads on its own. git_branch, long_command, and theme_cycle ship as examples you copy into the plugins directory. theme_cycle adds palette entries for the next theme and a crimson theme. Its Ctrl+Alt+T line is rejected, because that chord is already Time Travel. --lua-unsafe gives config.lua the full Lua library, including io and os.execute.

deathterminal --plugins list|enable <name>|disable <name> · --no-plugins

Run it

Window or headless

The default is headless. --gui opens a native window (Wayland, X11, Win32, or Cocoa) and falls back to headless if that fails. --version and --help print and exit. --ai-setup prints whether config, Ollama, the model, and the voice key are ready. It does not print the key.

deathterminal --gui · --headless · --config <file>

One-command install

These scripts are in the repo. They are separate from the release packages in the download section above. On Windows the PowerShell script installs a per-user deathterminal.exe, adds it to the user PATH, and makes a Start Menu shortcut that runs --gui. On macOS and Linux the shell script installs a prebuilt binary from the nightly branch. Zig 0.13 cannot link the GUI on current macOS, so a missing prebuilt stops instead of compiling. Run either command again to update.

irm https://raw.githubusercontent.com/AndrewGrayYouNeeK/Death-terminal-/main/install.ps1 | iex

curl -fsSL https://raw.githubusercontent.com/AndrewGrayYouNeeK/Death-terminal-/main/install.sh | sh

Uninstall

$env:DEATHTERMINAL_UNINSTALL='1'; irm https://raw.githubusercontent.com/AndrewGrayYouNeeK/Death-terminal-/main/install.ps1 | iex

curl -fsSL https://raw.githubusercontent.com/AndrewGrayYouNeeK/Death-terminal-/main/install.sh | sh -s -- --uninstall

Limits, stated in the code

No phone build Plan only

docs/MOBILE.md is a plan. There is no iOS or Android target. The VT grid and the software renderer are the portable pieces. The window, Vulkan surface, PTY, and SSH client are desktop code.

macOS and Windows Not fully proven

The Cocoa backend is in the tree and cross-compiles. The platforms note says it has not been run on a Mac. Live resize, IME, and dead keys are called out as untested. Windows GUI, Vulkan, and the palette were exercised under Wine. An interactive ConPTY shell was not, because Wine does not wire those handles. Real Windows is what that path is written for.

Terminal compatibility Partial

TERM is xterm-256color. Headless checks cover vim, less, htop, and tmux, including 256 colours and splits. Not implemented: sixel, soft fonts, VT52, left and right margins, double-width lines, reflow on resize, blinking text, and underline colour. 80/132-column mode resizes a headless grid only. In a window it clears and homes, and the width stays the window’s. OSC 52 is handled. The selection UI is outside the emulator.

Install

macOS

Open the .dmg and drag YouNeeK Death Terminal to Applications. That is the app bundle name. The binary is deathterminal.

When the Apple signing secrets are set, the release .dmg is notarized. Otherwise Gatekeeper blocks the first open.

  1. Open YouNeeK Death Terminal. macOS says it cannot check the app for malicious software.
  2. System Settings → Privacy & Security. Find the YouNeeK Death Terminal block and click Open Anyway.
  3. Confirm Open.

Right-click the app → Open → Open hits the same gate.

Windows

Run the setup .exe. Per-user install. The Start Menu shortcut launches the GUI. The exe is unsigned, so SmartScreen can warn until signing lands.

First run

No config.lua is required. The death theme and the other defaults are already on. AI suggestions are optional. The first time Ollama is missing, a short hint shows the pull command and then stays out of the way. Check it without opening a window:

ollama pull qwen2.5-coder:0.5b
deathterminal --ai-setup

Linux

x86_64 packages.

chmod +x deathterminal-*-x86_64.AppImage
./deathterminal-*-x86_64.AppImage

No FUSE: add --appimage-extract-and-run.

sudo apt install ./deathterminal_*_amd64.deb
sudo dnf install ./deathterminal-*.x86_64.rpm

Verify

Check the file against SHA256SUMS from the same release.

sha256sum -c SHA256SUMS
